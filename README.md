# WordLift Telugu

A mobile-first English vocabulary PWA with Telugu meanings, bilingual examples, swipe cards, pronunciation, quiz scoring, local progress, and Android home-screen support.

## Run
Serve this folder from any static web host or local HTTP server. Open the site in Chrome on Android and choose **Add to Home screen**.

The starter lesson contains 10 sample words. Replace the `WORDS` array in `index.html` with your own vocabulary/content or connect it to an API/database.
